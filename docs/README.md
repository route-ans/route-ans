# Configuration Documentation

This directory contains MkDocs-based configuration documentation.

## Setup

```bash
# Install dependencies
pip install -r requirements.txt

# Serve locally
mkdocs serve

# Build static site
mkdocs build
```

## Viewing

- **Local development:** http://localhost:8000
- **Built site:** `site/` directory

## Structure

- `mkdocs.yml` - MkDocs configuration
- `docs/index.md` - Landing page
- `docs/configuration/reference.md` - Complete configuration API reference
- `docs/configuration/feature-flags.md` - Feature flags documentation
